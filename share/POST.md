## LinkedIn post

I got tired of opening 20 tabs every morning to figure out what actually happened in tech, so I built a tool to do it for me. 🛠️

**Trend Pool** watches ~300 sources every hour: company newsrooms (OpenAI, Google, Apple, NVIDIA, Microsoft…), tech and AI media, Hacker News, Product Hunt and Google Trends, in English and Turkish.

Then it does the boring part:
🔁 Merges the same story from different sites into one topic. "×4" means four outlets are covering it.
📈 Ranks topics by real signals: engagement, how many sources picked it up, whether it's a launch, and how fresh it is.
🔎 Shows why each story ranks where it does, with no black box.
🏷️ Adds categories, tags and publish dates, so you can jump straight to AI, launches, hardware, security or Türkiye.
📤 Exports to CSV/JSON and has an API, so other tools can use the feed.

It started as a way to find things worth posting about. Now it's the first tab I open every day.

Built with Next.js, PostgreSQL and Docker, using only free public feeds.

Try it / see the code: [link]

Feedback is very welcome, especially sources I should add. 👇
